CONFIGURATION
       See git-config(1) for core variables and git-diff(1) for settings related to diff generation.

       format.pretty
           Default for the --format option. (See Pretty Formats above.) Defaults to medium.

       i18n.logOutputEncoding
           Encoding to use when displaying logs. (See Discussion above.) Defaults to the value of i18n.commitEncoding if set, and UTF-8 otherwise.

       log.date
           Default format for human-readable dates. (Compare the --date option.) Defaults to "default", which means to write dates like Sat May 8 19:35:34 2010 -0500.

           If the format is set to "auto:foo" and the pager is in use, format "foo" will be the used for the date format. Otherwise "default" will be used.

       log.follow
           If true, git log will act as if the --follow option was used when a single <path> is given. This has the same limitations as --follow, i.e. it cannot be used to follow
           multiple files and does not work well on non-linear history.

       log.showRoot
           If false, git log and related commands will not treat the initial commit as a big creation event. Any root commits in git log -p output would be shown without a diff
           attached. The default is true.

       log.showSignature
           If true, git log and related commands will act as if the --show-signature option was passed to them.

       mailmap.*
           See git-shortlog(1).

       notes.displayRef
           Which refs, in addition to the default set by core.notesRef or GIT_NOTES_REF, to read notes from when showing commit messages with the log family of commands. See git-
           notes(1).

           May be an unabbreviated ref name or a glob and may be specified multiple times. A warning will be issued for refs that do not exist, but a glob that does not match any refs
           is silently ignored.

           This setting can be disabled by the --no-notes option, overridden by the GIT_NOTES_DISPLAY_REF environment variable, and overridden by the --notes=<ref> option.
