NAME
       function::ppfunc - Returns the function name parsed from pp

SYNOPSIS
           ppfunc:string()

ARGUMENTS
       None

DESCRIPTION
       This returns the function name from the current pp. Not all pp have functions in them, in which case "" is
       returned.
