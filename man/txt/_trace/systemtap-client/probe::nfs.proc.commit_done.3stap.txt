NAME
       probe::nfs.proc.commit_done - NFS client response to a commit RPC task

SYNOPSIS
       nfs.proc.commit_done

VALUES
       version
           NFS version

       valid
           fattr->valid, indicates which fields are valid

       server_ip
           IP address of server

       count
           number of bytes committed

       status
           result of last operation

       timestamp
           V4 timestamp, which is used for lease renewal

       prot
           transfer protocol

DESCRIPTION
       Fires when a reply to a commit RPC task is received or some commit operation error occur (timeout or socket
       shutdown).

SEE ALSO
       tapset::nfs_proc(3stap)
