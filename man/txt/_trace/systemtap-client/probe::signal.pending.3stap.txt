NAME
       probe::signal.pending - Examining pending signal

SYNOPSIS
       signal.pending

VALUES
       sigset_size
           The size of the user-space signal set

       name
           Name of the probe point

       sigset_add
           The address of the user-space signal set (sigset_t)

DESCRIPTION
       This probe is used to examine a set of signals pending for delivery to a specific thread. This normally occurs
       when the do_sigpending kernel function is executed.
