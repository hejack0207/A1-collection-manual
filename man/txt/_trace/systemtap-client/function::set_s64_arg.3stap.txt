NAME
       function::set_s64_arg - Set function argument as signed 64-bit value

SYNOPSIS
           set_s64_arg(n:long,v:long)

ARGUMENTS
       n
           index of argument to return

       v
           value to set

DESCRIPTION
       Set the signed 64-bit value of argument n, same as longlong_arg.
