NAME
       function::tz_gmtoff - Return local time zone offset

SYNOPSIS
           tz_gmtoff()

ARGUMENTS
       None

DESCRIPTION
       Returns the local time zone offset (seconds west of UTC), as passed by staprun at script startup only.

SEE ALSO
       tapset::tzinfo(3stap)
