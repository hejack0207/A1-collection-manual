NAME
       function::set_user_pointer - Writes a pointer value to user memory.

SYNOPSIS
           set_user_pointer(addr:long,val:long)

ARGUMENTS
       addr
           The user address to write the pointer to

       val
           The pointer which is to be written

DESCRIPTION
       Writes the pointer value to a given user memory address. Reports an error when writing to the given address
       fails. Requires the use of guru mode (-g).
