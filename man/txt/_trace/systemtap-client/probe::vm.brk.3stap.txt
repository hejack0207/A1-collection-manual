NAME
       probe::vm.brk - Fires when a brk is requested (i.e. the heap will be resized)

SYNOPSIS
       vm.brk

VALUES
       address
           the requested address

       name
           name of the probe point

       length
           the length of the memory segment

CONTEXT
       The process calling brk.

       tapset::memory(3stap)
