NAME
       probe::nfs.proc.remove - NFS client removes a file on server

SYNOPSIS
       nfs.proc.remove

VALUES
       filename
           file name

       prot
           transfer protocol

       fh
           file handle of parent dir

       server_ip
           IP address of server

       filelen
           length of file name

       version
           NFS version (the function is used for all NFS version)

       tapset::nfs_proc(3stap)
