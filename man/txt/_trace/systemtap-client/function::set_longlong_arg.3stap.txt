NAME
       function::set_longlong_arg - Set function argument as 64-bit value

SYNOPSIS
           set_longlong_arg:long(n:long,v:long)

ARGUMENTS
       n
           index of argument to return

       v
           value to set

DESCRIPTION
       Set the value of argument n as a 64-bit value.
