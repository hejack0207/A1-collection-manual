NAME
       function::tcpmib_remote_addr - Get the remote address

SYNOPSIS
           tcpmib_remote_addr:long(sk:long)

ARGUMENTS
       sk
           pointer to a struct inet_sock

DESCRIPTION
       Returns the daddr from a struct inet_sock in host order.
