NAME
       probe::stap.system.spawn - stap spawned new process

SYNOPSIS
       stap.system.spawn

VALUES
       pid
           the pid of the spawned process

       ret
           the return value from posix_spawn

DESCRIPTION
       Fires just after the call to posix_spawn.

       tapset::stap_staticmarkers(3stap)
