NAME
       function::task_ns_gid - The group identifier of the task as seen in a namespace

SYNOPSIS
           task_ns_gid:long(task:long)

ARGUMENTS
       task
           task_struct pointer

DESCRIPTION
       This function returns the group id of the given task as seen in in the given user namespace.
