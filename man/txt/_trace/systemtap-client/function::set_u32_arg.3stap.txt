NAME
       function::set_u32_arg - Set function argument as unsigned 32-bit value

SYNOPSIS
           set_u32_arg(n:long,v:long)

ARGUMENTS
       n
           index of argument to return

       v
           value to set

DESCRIPTION
       Set the unsigned 32-bit value of argument n, same as uint_arg.
