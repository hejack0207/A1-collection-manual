NAME
       probe::udp.sendmsg.return - Fires whenever an attempt to send a UDP message is completed

SYNOPSIS
       udp.sendmsg.return

VALUES
       name
           The name of this probe

       size
           Number of bytes sent by the process

CONTEXT
       The process which sent a UDP message
