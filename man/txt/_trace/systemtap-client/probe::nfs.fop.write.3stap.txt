NAME
       probe::nfs.fop.write - NFS client write operation

SYNOPSIS
       nfs.fop.write

VALUES
       devname
           block device name

DESCRIPTION
       SystemTap uses the vfs.do_sync_write probe to implement this probe and as a result will get operations other
       than the NFS client write operations.
