NAME
       function::set_user_int - Writes an int value to user memory

SYNOPSIS
           set_user_int(addr:long,val:long)

ARGUMENTS
       addr
           The user address to write the int to

       val
           The int which is to be written

DESCRIPTION
       Writes the int value to a given user memory address. Reports an error when writing to the given address fails.
       Requires the use of guru mode (-g).
