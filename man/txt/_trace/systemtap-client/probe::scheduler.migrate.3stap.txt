NAME
       probe::scheduler.migrate - Task migrating across cpus

SYNOPSIS
       scheduler.migrate

VALUES
       name
           name of the probe point

       cpu_from
           the original cpu

       task
           the process that is being migrated

       cpu_to
           the destination cpu

       priority
           priority of the task being migrated

       pid
           PID of the task being migrated

       tapset::scheduler(3stap)
