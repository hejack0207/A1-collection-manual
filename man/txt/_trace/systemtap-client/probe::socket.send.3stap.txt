NAME
       probe::socket.send - Message sent on a socket.

SYNOPSIS
       socket.send

VALUES
       family
           Protocol family value

       success
           Was send successful? (1 = yes, 0 = no)

       protocol
           Protocol value

       size
           Size of message sent (in bytes) or error code if success = 0

       name
           Name of this probe

       type
           Socket type value

       flags
           Socket flags value

       state
           Socket state value

CONTEXT
       The message sender

SEE ALSO
       tapset::socket(3stap)
