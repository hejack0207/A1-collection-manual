NAME
       function::fp_mul - Multiplication between floating points

SYNOPSIS
           fp_mul:long(mul1:long,mul2:long)

ARGUMENTS
       mul1
           the 64 bit floating point multiplicand

       mul2
           64 bit floating point multiplier

DESCRIPTION
       result is multiplicand times multiplier
