NAME
       function::user_int_warn - Retrieves an int value stored in user space

SYNOPSIS
           user_int_warn:long(addr:long)

ARGUMENTS
       addr
           the user space address to retrieve the int from

DESCRIPTION
       Returns the int value from a given user space address. Returns zero when user space data is not accessible and
       warns about the failure (but does not error).
