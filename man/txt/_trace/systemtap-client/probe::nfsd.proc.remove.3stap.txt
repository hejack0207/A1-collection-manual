NAME
       probe::nfsd.proc.remove - NFS server removing a file for client

SYNOPSIS
       nfsd.proc.remove

VALUES
       gid
           requester's group id

       version
           nfs version

       filename
           file name

       filelen
           length of file name

       proto
           transfer protocol

       client_ip
           the ip address of client

       fh
           file handle (the first part is the length of the file handle)

       uid
           requester's user id

       tapset::nfsd(3stap)
