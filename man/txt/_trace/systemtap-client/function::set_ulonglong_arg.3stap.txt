NAME
       function::set_ulonglong_arg - Set function argument as 64-bit value

SYNOPSIS
           set_ulonglong_arg(n:long,v:long)

ARGUMENTS
       n
           index of argument to return

       v
           value to set

DESCRIPTION
       Set the value of argument n as a 64-bit value. (Same as longlong_arg.)
