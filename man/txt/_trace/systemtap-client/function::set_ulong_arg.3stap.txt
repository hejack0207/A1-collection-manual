NAME
       function::set_ulong_arg - Set function argument as unsigned long

SYNOPSIS
           set_ulong_arg(n:long,v:long)

ARGUMENTS
       n
           index of argument to return

       v
           value to set

DESCRIPTION
       Set the value of argument n as an unsigned long. On architectures where a long is 32 bits, the value is
       zero-extended to 64 bits.
