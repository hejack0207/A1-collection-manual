NAME
       probe::tty.receive - called when a tty receives a message

SYNOPSIS
       tty.receive

VALUES
       cp
           the buffer that was received

       count
           The amount of characters received

       name
           the name of the module file

       index
           The tty Index

       id
           the tty id

       fp
           The flag buffer

       driver_name
           the driver name
