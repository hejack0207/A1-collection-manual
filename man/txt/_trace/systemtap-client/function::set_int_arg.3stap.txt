NAME
       function::set_int_arg - Set function argument as signed int

SYNOPSIS
           set_int_arg(n:long,v:long)

ARGUMENTS
       n
           index of argument to return

       v
           value to set

DESCRIPTION
       Set the value of argument n as a signed int (i.e., a 32-bit integer sign-extended to 64 bits).
