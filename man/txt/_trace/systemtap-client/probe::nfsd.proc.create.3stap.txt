NAME
       probe::nfsd.proc.create - NFS server creating a file for client

SYNOPSIS
       nfsd.proc.create

VALUES
       filename
           file name

       version
           nfs version

       gid
           requester's group id

       fh
           file handle (the first part is the length of the file handle)

       uid
           requester's user id

       client_ip
           the ip address of client

       proto
           transfer protocol

       filelen
           length of file name

       tapset::nfsd(3stap)
