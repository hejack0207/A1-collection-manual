NAME
       probe::nfsd.proc.commit - NFS server performing a commit operation for client

SYNOPSIS
       nfsd.proc.commit

VALUES
       size
           read bytes

       gid
           requester's group id

       version
           nfs version

       client_ip
           the ip address of client

       count
           read bytes

       proto
           transfer protocol

       offset
           the offset of file

       uid
           requester's user id

       fh
           file handle (the first part is the length of the file handle)

SEE ALSO
       tapset::nfsd(3stap)
