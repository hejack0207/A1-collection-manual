NAME
       tapset::context-envvar - systemtap context-envvar tapset

DESCRIPTION
        Context  functions  provide additional information about where an event occurred. These functions can provide
       information such as a backtrace to where the event occurred and the current register values for the processor.

       env_var
              Fetch environment variable from current process

              See function::env_var(3stap)
               for details.

SEE ALSO
        function::env_var(3stap),  stap(1), stapprobes(3stap)
