NAME
       function::s32_arg - Return function argument as signed 32-bit value

SYNOPSIS
           s32_arg:long(n:long)

ARGUMENTS
       n
           index of argument to return

DESCRIPTION
       Return the signed 32-bit value of argument n, same as int_arg.
