NAME
       probe::nfsd.rename - NFS server renaming a file for client

SYNOPSIS
       nfsd.rename

VALUES
       flen
           length of old file name

       client_ip
           the ip address of client

       tfh
           file handler of new path

       tname
           new file name

       fh
           file handler of old path

       filename
           old file name

       tlen
           length of new file name
