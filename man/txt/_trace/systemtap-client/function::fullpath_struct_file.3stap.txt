NAME
       function::fullpath_struct_file - get the full path

SYNOPSIS
           fullpath_struct_file:string(task:long,file:long)

ARGUMENTS
       task
           task_struct pointer.

       file
           Pointer to "struct file".

DESCRIPTION
       Returns the full dirent name (full path to the root), like the kernel d_path function.
