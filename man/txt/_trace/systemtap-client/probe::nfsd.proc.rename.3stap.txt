NAME
       probe::nfsd.proc.rename - NFS Server renaming a file for client

SYNOPSIS
       nfsd.proc.rename

VALUES
       tname
           new file name

       fh
           file handler of old path

       uid
           requester's user id

       flen
           length of old file name

       client_ip
           the ip address of client

       tfh
           file handler of new path

       gid
           requester's group id

       filename
           old file name

       tlen
           length of new file name
