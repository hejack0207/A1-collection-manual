NAME
       probe::staprun.remove_module - Removing SystemTap instrumentation module

SYNOPSIS
       staprun.remove_module

VALUES
       name
           the stap module name to be removed (without the .ko extension)

DESCRIPTION
       Fires just before the call to remove the module.
