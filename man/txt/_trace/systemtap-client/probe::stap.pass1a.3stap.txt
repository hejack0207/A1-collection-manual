NAME
       probe::stap.pass1a - Starting stap pass1 (parsing user script)

SYNOPSIS
       stap.pass1a

VALUES
       session
           the systemtap_session variable s

DESCRIPTION
       pass1a fires just after the call to gettimeofday, before the user script is parsed.
