NAME
       function::set_user_string - Writes a string to user memory

SYNOPSIS
           set_user_string(addr:long,val:string)

ARGUMENTS
       addr
           The user address to write the string to

       val
           The string which is to be written

DESCRIPTION
       Writes the given string to a given user memory address. Reports an error when writing to the given address
       fails. Requires the use of guru mode (-g).
