NAME
       function::user_short_error - Retrieves a short value stored in user space

SYNOPSIS
           user_short_error:long(addr:long)

ARGUMENTS
       addr
           the user space address to retrieve the short from

DESCRIPTION
       Returns the short value from a given user space address. If the user space data is not accessible, an error
       will occur.
