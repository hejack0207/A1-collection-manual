NAME
       probe::staprun.insert_module - Inserting SystemTap instrumentation module

SYNOPSIS
       staprun.insert_module

VALUES
       path
           the full path to the .ko kernel module about to be inserted

DESCRIPTION
       Fires just before the call to insert the module.
