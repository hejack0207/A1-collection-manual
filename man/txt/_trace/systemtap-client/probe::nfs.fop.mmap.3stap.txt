NAME
       probe::nfs.fop.mmap - NFS client mmap operation

SYNOPSIS
       nfs.fop.mmap

VALUES
       vm_start
           start address within vm_mm

       parent_name
           parent dir name

       buf
           the address of buf in user space

       ino
           inode number

       vm_end
           the first byte after end address within vm_mm

       file_name
           file name

       attrtimeo
           how long the cached information is assumed to be valid. We need to revalidate the cached attrs for this
           inode if jiffies - read_cache_jiffies > attrtimeo.

       dev
           device identifier

       cache_valid
           cache related bit mask flag

       vm_flag
           vm flags

       cache_time
           when we started read-caching this inode
