NAME
       probe::nfs.fop.llseek - NFS client llseek operation

SYNOPSIS
       nfs.fop.llseek

VALUES
       dev
           device identifier

       offset
           the offset of the file will be repositioned

       whence_str
           symbolic string representation of the position to seek from

       ino
           inode number

       whence
           the position to seek from
