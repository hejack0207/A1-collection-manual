NAME
       probe::nfs.aop.write_begin - NFS client begin to write data

SYNOPSIS
       nfs.aop.write_begin

VALUES
       dev
           device identifier

       ino
           inode number

       __page
           the address of page

       to
           end address of this write operation

       size
           write bytes

       page_index
           offset within mapping, can used a page identifier and position identifier in the page frame

       offset
           start address of this write operation

DESCRIPTION
       Occurs when write operation occurs on nfs. It prepare a page for writing, look for a request corresponding to
       the page. If there is one, and it belongs to another file, it flush it out before it tries to copy anything
       into the page. Also do the same if it finds a request from an existing dropped page
