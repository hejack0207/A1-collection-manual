NAME
       function::set_uint_arg - Set argument as unsigned int

SYNOPSIS
           set_uint_arg:long(n:long,v:long)

ARGUMENTS
       n
           index of argument to set

       v
           value to set

DESCRIPTION
       Set the value of argument n as an unsigned int (i.e., a 32-bit integer zero-extended to 64 bits).
