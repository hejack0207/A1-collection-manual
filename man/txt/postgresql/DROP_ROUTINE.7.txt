NAME
       DROP_ROUTINE - remove a routine

SYNOPSIS
       DROP ROUTINE [ IF EXISTS ] name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] [, ...]
           [ CASCADE | RESTRICT ]

DESCRIPTION
       DROP ROUTINE removes the definition of an existing routine, which can be an aggregate function, a normal
       function, or a procedure. See under DROP AGGREGATE (DROP_AGGREGATE(7)), DROP FUNCTION (DROP_FUNCTION(7)), and
       DROP PROCEDURE (DROP_PROCEDURE(7)) for the description of the parameters, more examples, and further details.

EXAMPLES
       To drop the routine foo for type integer:

           DROP ROUTINE foo(integer);

       This command will work independent of whether foo is an aggregate, function, or procedure.

COMPATIBILITY
       This command conforms to the SQL standard, with these PostgreSQL extensions:

       o   The standard only allows one routine to be dropped per command.

       o   The IF EXISTS option

       o   The ability to specify argument modes and names

       o   Aggregate functions are an extension.

SEE ALSO
       DROP AGGREGATE (DROP_AGGREGATE(7)), DROP FUNCTION (DROP_FUNCTION(7)), DROP PROCEDURE (DROP_PROCEDURE(7)),
       ALTER ROUTINE (ALTER_ROUTINE(7))

       Note that there is no CREATE ROUTINE command.
