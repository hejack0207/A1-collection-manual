NAME
       etcdctl - A simple command line client for etcd

SYNOPSIS
       [ETCDCTL_API=3] etctctl [OPTIONS]

DESCRIPTION
       Command  line  client for etcd.  Queries to v2 data model are available through etcdtl command (see etcdctl2(1)).  Queries to v3 data model are available through ETCDCTL=3 etcdtl
       command (see etcdctl3(1)).

       Find more information at ?https://github.com/coreos/etcd?.

SEE ALSO
       etcd(1), etcdctl2(1), etcdctl3(1)
