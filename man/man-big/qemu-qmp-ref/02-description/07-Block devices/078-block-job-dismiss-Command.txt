       block-job-dismiss  (Command) For jobs that have already concluded, remove them from the block-job-query list. This command only needs to be run for jobs which were started with
       QEMU 2.12+ job lifetime management semantics.

       This command will refuse to operate on any job that has not yet reached its terminal state, JOB_STATUS_CONCLUDED. For jobs that make use of the BLOCK_JOB_READY event, block-job-
       cancel or block-job-complete will still need to be used as appropriate.

       Arguments:

       "id: string"
           The job identifier.

       Returns: Nothing on success

       Since: 2.12
