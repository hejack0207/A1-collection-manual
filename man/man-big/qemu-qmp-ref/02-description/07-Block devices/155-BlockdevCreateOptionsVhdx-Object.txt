       BlockdevCreateOptionsVhdx (Object)

       Driver specific image creation options for vhdx.

       "file"             Node to create the image format on "size"             Size of the virtual disk in bytes "log-size"         Log size in bytes, must be a multiple of 1 MB
       (default: 1 MB) "block-size"       Block size in bytes, must be a multiple of 1 MB and not larger than 256 MB (default: automatically choose a block size depending on the image
       size) "subformat"        vhdx subformat (default: dynamic) "block-state-zero" Force use of payload blocks of type 'ZERO'. Non-standard, but default.  Do not set to 'off' when
       using 'qemu-img convert' with subformat=dynamic.
