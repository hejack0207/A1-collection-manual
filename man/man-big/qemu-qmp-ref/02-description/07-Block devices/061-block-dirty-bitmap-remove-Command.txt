       block-dirty-bitmap-remove  (Command) Stop write tracking and remove the dirty bitmap that was created with block-dirty-bitmap-add. If the bitmap is persistent, remove it from its
       storage too.

       Returns: nothing on success If "node" is not a valid block device or node, DeviceNotFound If "name" is not found, GenericError with an explanation if "name" is frozen by an
       operation, GenericError

       Since: 2.4

       Example:

               -> { "execute": "block-dirty-bitmap-remove",
                    "arguments": { "node": "drive0", "name": "bitmap0" } }
               <- { "return": {} }
