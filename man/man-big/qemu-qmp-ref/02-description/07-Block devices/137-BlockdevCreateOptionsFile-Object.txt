       BlockdevCreateOptionsFile (Object)

       Driver specific image creation options for file.

       "filename"         Filename for the new image file "size"             Size of the virtual disk in bytes "preallocation"    Preallocation mode for the new image (default: off)
       "nocow"            Turn off copy-on-write (valid only on btrfs; default: off)
