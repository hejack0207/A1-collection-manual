       BlockLatencyHistogramInfo (Object)

       Block latency histogram.

       Members:

       "boundaries: array of int"
           list of interval boundary values in nanoseconds, all greater than zero and in ascending order.  For example, the list [10, 50, 100] produces the following histogram
           intervals: [0, 10), [10, 50), [50, 100), [100, +inf).

       "bins: array of int"
           list of io request counts corresponding to histogram intervals.  len("bins") = len("boundaries") + 1 For the example above, "bins" may be something like [3, 1, 5, 2], and
           corresponding histogram looks like:

           5|           * 4|           * 3| 2|              * 1| +------------------ 10   50   100

       Since: 2.12
