       blockdev-backup  (Command) Start a point-in-time copy of a block device to a new destination.  The status of ongoing blockdev-backup operations can be checked with query-block-
       jobs where the BlockJobInfo.type field has the value 'backup'.  The operation can be stopped before it has completed using the block-job-cancel command.

       Arguments: the members of "BlockdevBackup"

       Returns: nothing on success If "device" is not a valid block device, DeviceNotFound

       Since: 2.3

       Example:

               -> { "execute": "blockdev-backup",
                    "arguments": { "device": "src-id",
                                   "sync": "full",
                                   "target": "tgt-id" } }
               <- { "return": {} }
