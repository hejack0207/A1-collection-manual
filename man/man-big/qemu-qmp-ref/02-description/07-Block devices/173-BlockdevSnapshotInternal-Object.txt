       BlockdevSnapshotInternal (Object)

       Members:

       "device: string"
           the device name or node-name of a root node to generate the snapshot from

       "name: string"
           the name of the internal snapshot to be created

       Notes: In transaction, if "name" is empty, or any snapshot matching "name" exists, the operation will fail. Only some image formats support it, for example, qcow2, rbd, and
       sheepdog.

       Since: 1.7
