       JobVerb (Enum)

       Represents command verbs that can be applied to a job.

       Values:

       "cancel"
           see "job-cancel"

       "pause"
           see "job-pause"

       "resume"
           see "job-resume"

       "set-speed"
           see "block-job-set-speed"

       "complete"
           see "job-complete"

       "dismiss"
           see "job-dismiss"

       "finalize"
           see "job-finalize"

       Since: 2.12

       JOB_STATUS_CHANGE  (Event) Emitted when a job transitions to a different status.

       Arguments:

       "id: string"
           The job identifier

       "status: JobStatus"
           The new job status

       Since: 3.0
