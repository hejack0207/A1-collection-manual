       BlockDirtyBitmapAdd (Object)

       Members:

       "node: string"
           name of device/node which the bitmap is tracking

       "name: string"
           name of the dirty bitmap

       "granularity: int" (optional)
           the bitmap granularity, default is 64k for block-dirty-bitmap-add

       "persistent: boolean" (optional)
           the bitmap is persistent, i.e. it will be saved to the corresponding block device image file on its close. For now only Qcow2 disks support persistent bitmaps. Default is
           false for block-dirty-bitmap-add. (Since: 2.10)

       "autoload: boolean" (optional)
           ignored and deprecated since 2.12.  Currently, all dirty tracking bitmaps are loaded from Qcow2 on open.

       "x-disabled: boolean" (optional)
           the bitmap is created in the disabled state, which means that it will not track drive changes. The bitmap may be enabled with x-block-dirty-bitmap-enable. Default is false.
           (Since: 3.0)

       Since: 2.4
