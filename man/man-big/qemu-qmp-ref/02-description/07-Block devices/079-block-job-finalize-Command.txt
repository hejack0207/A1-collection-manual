       block-job-finalize  (Command) Once a job that has manual=true reaches the pending state, it can be instructed to finalize any graph changes and do any necessary cleanup via this
       command.  For jobs in a transaction, instructing one job to finalize will force ALL jobs in the transaction to finalize, so it is only necessary to instruct a single member job
       to finalize.

       Arguments:

       "id: string"
           The job identifier.

       Returns: Nothing on success

       Since: 2.12
