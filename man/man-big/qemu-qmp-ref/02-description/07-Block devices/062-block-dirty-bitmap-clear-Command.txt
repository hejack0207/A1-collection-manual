       block-dirty-bitmap-clear  (Command) Clear (reset) a dirty bitmap on the device, so that an incremental backup from this point in time forward will only backup clusters modified
       after this clear operation.

       Returns: nothing on success If "node" is not a valid block device, DeviceNotFound If "name" is not found, GenericError with an explanation

       Since: 2.4

       Example:

               -> { "execute": "block-dirty-bitmap-clear",
                    "arguments": { "node": "drive0", "name": "bitmap0" } }
               <- { "return": {} }
