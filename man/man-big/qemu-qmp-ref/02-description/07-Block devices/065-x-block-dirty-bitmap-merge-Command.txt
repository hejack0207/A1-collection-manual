       x-block-dirty-bitmap-merge  (Command) FIXME: Rename "src_name" and "dst_name" to src-name and dst-name.

       Merge "src_name" dirty bitmap to "dst_name" dirty bitmap. "src_name" dirty bitmap is unchanged. On error, "dst_name" is unchanged.

       Returns: nothing on success If "node" is not a valid block device, DeviceNotFound If "dst_name" or "src_name" is not found, GenericError If bitmaps has different sizes or
       granularities, GenericError

       Since: 3.0

       Example:

               -> { "execute": "x-block-dirty-bitmap-merge",
                    "arguments": { "node": "drive0", "dst_name": "bitmap0",
                                   "src_name": "bitmap1" } }
               <- { "return": {} }
