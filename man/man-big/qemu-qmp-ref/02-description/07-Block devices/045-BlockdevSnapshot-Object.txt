       BlockdevSnapshot (Object)

       Members:

       "node: string"
           device or node name that will have a snapshot created.

       "overlay: string"
           reference to the existing block device that will become the overlay of "node", as part of creating the snapshot.  It must not have a current backing file (this can be
           achieved by passing "backing": null to blockdev-add).

       Since: 2.5
