       blockdev-snapshot  (Command) Generates a snapshot of a block device.

       Create a snapshot, by installing 'node' as the backing image of 'overlay'. Additionally, if 'node' is associated with a block device, the block device changes to using 'overlay'
       as its new active image.

       For the arguments, see the documentation of BlockdevSnapshot.

       Since: 2.5

       Example:

               -> { "execute": "blockdev-add",
                    "arguments": { "driver": "qcow2",
                                   "node-name": "node1534",
                                   "file": { "driver": "file",
                                             "filename": "hd1.qcow2" },
                                   "backing": null } }

               <- { "return": {} }

               -> { "execute": "blockdev-snapshot",
                    "arguments": { "node": "ide-hd0",
                                   "overlay": "node1534" } }
               <- { "return": {} }
