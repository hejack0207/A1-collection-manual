       set

              hostname <host>

                     Session hostname.

              username <user>

                     Session username.

              password <pass>

                     Session password.

              privlvl <level>

                     Session privilege level force.

              authtype <type>

                     Authentication type force.

              localaddr <addr>

                     Local IPMB address.

              targetaddr <addr>

                     Remote target IPMB address.

              port <port>

                     Remote RMCP port.

              csv [level]

                     Enable output in comma separated format.  Affects following commands: user, channel,  isol,  su-
                     noem, sol, sensor, sdr, sel, session.

              verbose [verbose]

                     Verbosity level.
