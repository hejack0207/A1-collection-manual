   define
       Syntax:

          define FILE [--validate]

       Define  a  domain from an XML <file>. Optionally, the format of the input XML file can be validated against an
       internal RNG schema with --validate (identical to using virt-xml-validate(1) tool). The domain  definition  is
       registered but not started.  If domain is already running, the changes will take effect on the next boot.
