   iface-bridge
       Syntax:

          iface-bridge interface bridge [--no-stp] [delay] [--no-start]

       Create a bridge device named bridge, and attach the existing network device interface to the new bridge.   The
       new  bridge defaults to starting immediately, with STP enabled and a delay of 0; these settings can be altered
       with --no-stp, --no-start, and an integer number of seconds for delay. All IP address configuration of  inter-
       face will be moved to the new bridge device.

       See also iface-unbridge for undoing this operation.
