   numatune
       Syntax:

          numatune domain [--mode mode] [--nodeset nodeset]
             [[--config] [--live] | [--current]]

       Set  or get a domain's numa parameters, corresponding to the <numatune> element of domain XML.  Without flags,
       the current settings are displayed.

       mode can be one of `strict', `interleave' and `preferred' or any valid number from  the  virDomainNumatuneMem-
       Mode  enum  in  case the daemon supports it.  For a running domain, the mode can't be changed, and the nodeset
       can be changed only if the domain was started with a mode of `strict'.

       nodeset is a list of numa nodes used by the host for running the domain.  Its  syntax  is  a  comma  separated
       list, with '-' for ranges and '^' for excluding a node.

       If  --live  is  specified, set scheduler information of a running guest.  If --config is specified, affect the
       next boot of a persistent guest.  If --current is specified, affect the current guest state.

       For running guests in Linux hosts, the changes made in the domain's numa parameters does not  imply  that  the
       guest  memory  will be moved to a different nodeset immediately. The memory migration depends on the guest ac-
       tivity, and the memory of an idle guest will remain in its previous nodeset for longer. The presence  of  VFIO
       devices  will  also  lock parts of the guest memory in the same nodeset used to start the guest, regardless of
       nodeset changes.
