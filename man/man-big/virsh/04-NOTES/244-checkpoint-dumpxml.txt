   checkpoint-dumpxml
       Syntax:

          checkpoint-dumpxml domain checkpoint [--security-info] [--no-domain] [--size]

       Output  the  checkpoint XML for the domain's checkpoint named checkpoint.  Using --security-info will also in-
       clude security sensitive information.  Using --size will add XML indicating the current size in bytes of guest
       data  that  has changed since the checkpoint was created (although remember that guest activity between a size
       check and actually creating a backup can result in the backup needing slightly more space).  Using --no-domain
       will omit the <domain> element from the output for a more compact view.
