   iface-begin
       Syntax:

          iface-begin

       Create a snapshot of current host interface settings, which can later be committed (iface-commit) or  restored
       (iface-rollback).   If  a snapshot already exists, then this command will fail until the previous snapshot has
       been committed or restored.  Undefined behavior results if any external changes are made  to  host  interfaces
       outside of the libvirt API between the beginning of a snapshot and its eventual commit or rollback.
