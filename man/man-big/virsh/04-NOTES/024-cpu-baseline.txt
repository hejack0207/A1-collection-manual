   cpu-baseline
       Syntax:

          cpu-baseline FILE [--features] [--migratable]

       Compute  baseline  CPU which will be supported by all host CPUs given in <file>.  (See hypervisor-cpu-baseline
       command to get a CPU which can be provided by a specific hypervisor.) The list of host CPUs is  built  by  ex-
       tracting all <cpu> elements from the <file>. Thus, the <file> can contain either a set of <cpu> elements sepa-
       rated by new lines or even a set of complete <capabilities> elements  printed  by  capabilities  command.   If
       --features  is specified, then the resulting XML description will explicitly include all features that make up
       the CPU, without this option features that are part of the CPU model will not be listed in  the  XML  descrip-
       tion.   If --migratable is specified, features that block migration will not be included in the resulting CPU.
