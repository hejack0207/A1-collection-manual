   capabilities
       Syntax:

          capabilities

       Print an XML document describing the capabilities of the hypervisor we are currently connected  to.  This  in-
       cludes a section on the host capabilities in terms of CPU and features, and a set of description for each kind
       of guest which can be virtualized. For a more complete description see:

       https://libvirt.org/formatcaps.html

       The XML also show the NUMA topology information if available.
