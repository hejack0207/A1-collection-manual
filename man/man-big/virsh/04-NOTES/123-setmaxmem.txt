   setmaxmem
       Syntax:

          setmaxmem domain size [[--config] [--live] | [--current]]

       Change the maximum memory allocation limit for a guest domain.  If  --live  is  specified,  affect  a  running
       guest.   If --config is specified, affect the next boot of a persistent guest.  If --current is specified, af-
       fect the current guest state.  Both --live and --config flags may be given, but --current is exclusive. If  no
       flag is specified, behavior is different depending on hypervisor.

       Some  hypervisors  such  as  QEMU/KVM don't support live changes (especially increasing) of the maximum memory
       limit.  Even persistent configuration changes might not be performed with some hypervisors/configuration (e.g.
       on NUMA enabled domains on QEMU).  For complex configuration changes use command edit instead).

       size is a scaled integer (see NOTES above); it defaults to kibibytes (blocks of 1024 bytes) unless you provide
       a suffix (and the older option name --kilobytes is available as a deprecated synonym) .  Libvirt rounds up  to
       the  nearest  kibibyte.   Some hypervisors require a larger granularity than KiB, and requests that are not an
       even multiple will be rounded up.  For example,  vSphere/ESX  rounds  the  parameter  up  to  mebibytes  (1024
       kibibytes).
