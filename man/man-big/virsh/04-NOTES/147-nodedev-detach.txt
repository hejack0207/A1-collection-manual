   nodedev-detach
       Syntax:

          nodedev-detach nodedev [--driver backend_driver]

       Detach  nodedev from the host, so that it can safely be used by guests via <hostdev> passthrough.  This is re-
       versed with nodedev-reattach, and is done automatically for managed devices.

       Different backend drivers expect the device to be bound to different dummy devices. For example, QEMU's  "kvm"
       backend driver (the default) expects the device to be bound to pci-stub, but its "vfio" backend driver expects
       the device to be bound to vfio-pci. The --driver parameter can be used to specify the desired backend driver.
