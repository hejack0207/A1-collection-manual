   vol-key
       Syntax:

          vol-key vol-name-or-path [--pool pool-or-uuid]

       Return the volume key for a given volume.

       vol-name-or-path is the name or path of the volume to return the volume key.

       --pool  pool-or-uuid  is the name or UUID of the storage pool the volume is in. If the volume name is provided
       instead of the path, then providing the pool is necessary to find the volume to be uploaded  into;  otherwise,
       the first volume found by the path will be used.
