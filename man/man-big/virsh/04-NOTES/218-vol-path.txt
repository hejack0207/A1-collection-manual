   vol-path
       Syntax:

          vol-path vol-name-or-key [--pool pool-or-uuid]

       Return the path for a given volume.

       vol-name-or-key is the name or key of the volume to return the path.

       --pool  pool-or-uuid  is the name or UUID of the storage pool the volume is in. If the volume name is provided
       instead of the key, then providing the pool is necessary to find the volume to be  uploaded  into;  otherwise,
       the first volume found by the key will be used.
