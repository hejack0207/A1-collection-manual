   domdisplay
       Syntax:

          domdisplay domain [--include-password] [[--type] type] [--all]

       Output a URI which can be used to connect to the graphical display of the domain via VNC, SPICE or  RDP.   The
       particular  graphical  display type can be selected using the type parameter (e.g. "vnc", "spice", "rdp").  If
       --include-password is specified, the SPICE channel password will be included in the URI. If  --all  is  speci-
       fied, then all show all possible graphical displays, for a VM could have more than one graphical displays.
