   nodedev-create
       Syntax:

          nodedev-create FILE

       Create a device on the host node that can then be assigned to virtual machines. Normally, libvirt is  able  to
       automatically  determine which host nodes are available for use, but this allows registration of host hardware
       that libvirt did not automatically detect.  file contains xml for a top-level <device> description of  a  node
       device.
