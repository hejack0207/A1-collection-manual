   connect
       Syntax:

          connect [URI] [--readonly]

       (Re)-Connect to the hypervisor. When the shell is first started, this is automatically run with the URI param-
       eter  requested by the -c option on the command line. The URI parameter specifies how to connect to the hyper-
       visor. The URI docs https://libvirt.org/uri.html list the values supported, but the most common are:

       o xen:///system

         this is used to connect to the local Xen hypervisor

       o qemu:///system

         connect locally as root to the daemon supervising QEMU and KVM domains

       o qemu:///session

         connect locally as a normal user to his own set of QEMU and KVM domains

       o lxc:///system

         connect to a local linux container

       To find the currently used URI, check the uri command documented below.

       For remote access see the URI docs https://libvirt.org/uri.html on how to make URIs. The --readonly option al-
       lows for read-only connection
