   domxml-to-native
       Syntax:

          domxml-to-native format { [--xml] xml | --domain domain-name-or-id-or-uuid }

       Convert  the file xml into domain XML format or convert an existing --domain to the native guest configuration
       format named by format.  The xml and --domain arguments are mutually exclusive. For the types of format  argu-
       ment, refer to domxml-from-native.
