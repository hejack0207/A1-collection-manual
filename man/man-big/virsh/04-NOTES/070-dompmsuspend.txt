   dompmsuspend
       Syntax:

          dompmsuspend domain target [--duration]

       Suspend a running domain into one of these states (possible target values):

       o mem - equivalent of S3 ACPI state

       o disk - equivalent of S4 ACPI state

       o hybrid - RAM is saved to disk but not powered off

       The --duration argument specifies number of seconds before the domain is woken up after it was suspended  (see
       also dompmwakeup). Default is 0 for unlimited suspend time. (This feature isn't currently supported by any hy-
       pervisor driver and 0 should be used.).

       Note that this command requires a guest agent configured and running in the domain's guest OS.

       Beware that at least for QEMU, the domain's process will be terminated when target disk  is  used  and  a  new
       process  will  be  launched  when  libvirt  is  asked  to wake up the domain. As a result of this, any runtime
       changes, such as device hotplug or memory settings, are lost unless such changes were made with --config flag.
