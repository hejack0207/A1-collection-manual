   set-lifecycle-action
       Syntax:

          set-lifecycle-action domain type action
             [[--config] [--live] | [--current]]

       Set  the lifecycle action for specified lifecycle type.  The valid types are "poweroff", "reboot" and "crash",
       and for each of them valid action is one of "destroy",  "restart",  "rename-restart",  "preserve".   For  type
       "crash", additional actions "coredump-destroy" and "coredump-restart" are supported.
