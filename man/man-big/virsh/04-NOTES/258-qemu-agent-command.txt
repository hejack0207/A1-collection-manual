   qemu-agent-command
       Syntax:

          qemu-agent-command domain [--timeout seconds | --async | --block] command...

       Send an arbitrary guest agent command command to domain domain through QEMU  agent.   --timeout,  --async  and
       --block  options  are  exclusive.   --timeout  requires timeout seconds seconds and it must be positive.  When
       --aysnc is given, the command waits for timeout whether success or failed. And when --block is given, the com-
       mand waits forever with blocking timeout.
