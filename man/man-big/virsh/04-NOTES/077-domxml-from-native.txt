   domxml-from-native
       Syntax:

          domxml-from-native format config

       Convert  the  file config in the native guest configuration format named by format to a domain XML format. For
       QEMU/KVM hypervisor, the format argument must be qemu-argv. For Xen hypervisor, the  format  argument  may  be
       xen-xm,  xen-xl, or xen-sxpr. For LXC hypervisor, the format argument must be lxc-tools. For VMware/ESX hyper-
       visor, the format argument must be vmware-vmx.   For  the  Bhyve  hypervisor,  the  format  argument  must  be
       bhyve-argv.
