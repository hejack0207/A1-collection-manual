   domiflist
       Syntax:

          domiflist domain [--inactive]

       Print a table showing the brief information of all virtual interfaces associated with domain. If --inactive is
       specified, query the virtual interfaces that will be used on the next boot, rather than those currently in use
       by a running domain. Other contexts that require a MAC address of virtual interface (such as  detach-interface
       or domif-setlink) will accept the MAC address printed by this command.
