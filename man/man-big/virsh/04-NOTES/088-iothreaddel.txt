   iothreaddel
       Syntax:

          iothreaddel domain iothread_id [[--config] [--live] | [--current]]

       Delete an IOThread from the domain using the specified iothread_id.  If an IOThread is currently assigned to a
       disk resource such as via the attach-disk command, then the attempt to remove the IOThread will fail.  If  the
       iothread_id does not exist an error will occur.

       If --live is specified, affect a running guest. If the guest is not running an error is returned.  If --config
       is specified, affect the next boot of a persistent guest.  If --current is specified or  --live  and  --config
       are not specified, affect the current guest state.
