   emulatorpin
       Syntax:

          emulatorpin domain [cpulist] [[--live] [--config]  | [--current]]

       Query or change the pinning of domain's emulator threads to host physical CPUs.

       See vcpupin for cpulist.

       If  --live  is specified, affect a running guest.  If --config is specified, affect the next boot of a persis-
       tent guest.  If --current is specified, affect the current guest state.  Both --live and --config flags may be
       given  if  cpulist is present, but --current is exclusive.  If no flag is specified, behavior is different de-
       pending on hypervisor.
