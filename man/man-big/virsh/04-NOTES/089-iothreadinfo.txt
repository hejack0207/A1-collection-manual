   iothreadinfo
       Syntax:

          iothreadinfo domain [[--live] [--config] | [--current]]

       Display basic domain IOThreads information including the IOThread ID and the CPU Affinity for each IOThread.

       If  --live  is specified, get the IOThreads data from the running guest. If the guest is not running, an error
       is returned.  If --config is specified, get the IOThreads data from the next boot of a persistent  guest.   If
       --current  is specified or --live and --config are not specified, then get the IOThread data based on the cur-
       rent guest state.
