   domifstat
       Syntax:

          domifstat domain interface-device

       Get  network  interface  stats for a running domain. The network interface stats are only available for inter-
       faces that have a physical source interface. This does not include, for example, a 'user' interface type since
       it is a virtual LAN with NAT to the outside world. interface-device can be the interface target by name or MAC
       address.
