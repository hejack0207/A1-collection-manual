   node
       Syntax:

          node-memory-tune [shm-pages-to-scan] [shm-sleep-millisecs] [shm-merge-across-nodes]

       Allows you to display or set the node memory parameters.  shm-pages-to-scan can be used to set the  number  of
       pages  to scan before the shared memory service goes to sleep; shm-sleep-millisecs can be used to set the num-
       ber of millisecs the shared memory service should sleep before next scan; shm-merge-across-nodes specifies  if
       pages from different numa nodes can be merged. When set to 0, only pages which physically reside in the memory
       area of same NUMA node can be merged. When set to 1, pages from all nodes can be merged. Default to 1.

       Note: Currently the "shared memory service" only means KSM (Kernel Samepage Merging).
