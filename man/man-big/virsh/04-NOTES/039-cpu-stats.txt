   cpu-stats
       Syntax:

          cpu-stats domain [--total] [start] [count]

       Provide cpu statistics information of a domain. The domain should be running. Default it shows stats  for  all
       CPUs,  and  a  total.  Use --total for only the total stats, start for only the per-cpu stats of the CPUs from
       start, count for only count CPUs' stats.
