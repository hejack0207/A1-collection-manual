   domblklist
       Syntax:

          domblklist domain [--inactive] [--details]

       Print  a  table  showing  the  brief information of all block devices associated with domain. If --inactive is
       specified, query the block devices that will be used on the next boot, rather than those currently in use by a
       running  domain.  If  --details  is specified, disk type and device value will also be printed. Other contexts
       that require a block device name (such as domblkinfo or snapshot-create for disk snapshots) will accept either
       target or unique source names printed by this command.
