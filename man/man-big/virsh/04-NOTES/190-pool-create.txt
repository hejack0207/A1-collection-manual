   pool-create
       Syntax:

          pool-create file [--build] [[--overwrite] | [--no-overwrite]]

       Create and start a pool object from the XML file.

       [--build]  [[--overwrite]  | [--no-overwrite]] perform a pool-build after creation in order to remove the need
       for a follow-up command to build the pool. The --overwrite and --no-overwrite flags follow the same  rules  as
       pool-build. If just --build is provided, then pool-build is called with no flags.
