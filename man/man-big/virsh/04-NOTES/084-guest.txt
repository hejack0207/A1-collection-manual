   guest
       Syntax:

          guest-agent-timeout domain --timeout value

       Set  how long to wait for a response from guest agent commands. By default, agent commands block forever wait-
       ing for a response. value must be a positive value (wait for given amount of seconds) or one of the  following
       values:

       o -2 - block forever waiting for a result,

       o -1 - reset timeout to the default value,

       o 0 - do not wait at all,
