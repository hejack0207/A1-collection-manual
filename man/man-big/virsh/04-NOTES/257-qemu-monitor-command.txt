   qemu-monitor-command
       Syntax:

          qemu-monitor-command domain { [--hmp] | [--pretty] [--return-value] } command...

       Send an arbitrary monitor command command to domain domain through the QEMU monitor.  The results of the  com-
       mand will be printed on stdout.

       If  more than one argument is provided for command, they are concatenated with a space in between before pass-
       ing the single command to the monitor.

       Note that libvirt uses the QMP to talk to qemu so command must be valid JSON in QMP format to work properly.

       If --pretty is given the QMP reply is pretty-printed.

       If --return-value is given the 'return' key of the QMP  response  object  is  extracted  rather  than  passing
       through the full reply from QEMU.

       If  --hmp  is  passed,  the command is considered to be a human monitor command and libvirt will automatically
       convert it into QMP and convert the result back.
