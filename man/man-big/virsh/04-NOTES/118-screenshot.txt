   screenshot
       Syntax:

          screenshot domain [imagefilepath] [--screen screenID]

       Takes a screenshot of a current domain console and stores it into a file.  Optionally, if the hypervisor  sup-
       ports  more displays for a domain, screenID allows specifying which screen will be captured. It is the sequen-
       tial number of screen. In case of multiple graphics cards, heads are enumerated before  devices,  e.g.  having
       two graphics cards, both with four heads, screen ID 5 addresses the second head on the second card.
