# ipmaddr(8)

"", SEPTEMBER 2009

**ipmaddr**
- adds, deletes, and displays multicast addresses
 

<a name="synopsis"></a>

# Synopsis

```
/usr/sbin/ipmaddr [<operation>] [<args>]
```


<a name="note"></a>

# Note


This program is obsolete. For replacement check **ip maddr**.


<a name="description"></a>

# Description

The **ipmaddr** command can perform one of the following operations:

**add**
- add a multicast address

**del**
- delete a multicast address

**show**
- list multicast addresses
