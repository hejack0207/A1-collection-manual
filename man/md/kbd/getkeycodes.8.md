# getkeycodes(8) - print kernel scancode-to-keycode mapping table

Local, 8 Nov 1994

```
getkeycodes
```

<a name="description"></a>

# Description

The
_getkeycodes_
command prints the kernel scancode-to-keycode mapping table.

<a name="options"></a>

# Options

None.
