# arch(1) - print machine hardware name (same as uname -m)

GNU coreutils 8.31, March 2019

```
arch [OPTION]...
```

<a name="description"></a>

# Description



Print machine architecture.

* **--help**  
  display this help and exit
* **--version**  
  output version information and exit
