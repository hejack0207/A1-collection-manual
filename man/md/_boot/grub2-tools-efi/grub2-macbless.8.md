# grub-macbless(1) - Mac-style bless utility for HFS or HFS+

Wed Feb 26 2014

```
grub-macbless [-p | --ppc] [-v | --verbose] [-x | --x86] FILE
```


<a name="description"></a>

# Description

**grub-mkimage** blesses a file on an HFS or HFS+ file system, so that it
can be used to boot a Mac.


<a name="options"></a>

# Options


* --ppc  
  Bless the file for use on PPC-based Macs.
  
* --verbose  
  Print verbose messages.
  
* --x86  
  Bless the file for use on x86-based Macs.
