# memdiskfind(1) - Simple utility to find a resident \fBmemdisk\fR instance.

memdiskfind, 17 Jan 2014

```
memdiskfind
```

<a name="description"></a>

# Description


The **memdiskfind** utility searches memory for a **memdisk** instance,
and, if found, outputs the parameters needed to use the \fphram driver in
Linux to map it.
