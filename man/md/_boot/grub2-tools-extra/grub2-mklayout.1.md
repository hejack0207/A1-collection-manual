# grub-mklayout(3) - Generate a GRUB keyboard layout file.

Wed Feb 26 2014

```
grub-mklayout [-i | --input=FILE] [-o | --output=FILE] .RS 15 [-v | --verbose]
```


<a name="description"></a>

# Description

**grub-mklayout** generates a GRUB keyboard layout description which corresponds with the Linux console layout description given as input.


<a name="options"></a>

# Options


* --input=_FILE_  
  Use _FILE_ as the input.  The default value is the standard input device.
  
* --output=_FILE_  
  Use _FILE_ as the output.  The default value is the standard output device.
  
* --verbose  
  Print verbose messages.
