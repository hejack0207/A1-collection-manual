# grub-kbdcomp(3) - Generate a GRUB keyboard layout file.

Wed Feb 26 2014

```
grub-kbdcomp <-o | --output=FILE> CKBMAP_ARGUMENTS
```


<a name="description"></a>

# Description

**grub-kbdcomp** processes an X keyboard layout description in
**keymaps**(5) format into a format that can be used by GRUB's **keymap**
command.


<a name="options"></a>

# Options


* **--output**=_FILE_  
  Write output to _FILE_.
