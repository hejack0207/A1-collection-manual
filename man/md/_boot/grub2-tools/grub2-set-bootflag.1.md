# grub-set-bootflag(1) - Set a bootflag in the GRUB environment block.

Tue Jun 12 2018

```
grub-set-bootflag <BOOTFLAG>
```


<a name="description"></a>

# Description

**grub-set-bootflag** is a command line to set bootflags in GRUB's
stored environment.


<a name="commands"></a>

# Commands


* **BOOTFLAG**  
      Bootflag to set, one of _boot\_success_ or _show\_menu\_once_.
