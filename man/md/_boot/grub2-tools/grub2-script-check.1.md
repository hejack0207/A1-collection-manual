# grub-script-check(3) - Check GRUB configuration file for syntax errors.

Wed Feb 26 2014

```
grub-script-check [-v | --verbose] PATH
```


<a name="description"></a>

# Description

**grub-script-check** verifies that a specified GRUB configuration file does not contain syntax errors.


<a name="options"></a>

# Options


* --verbose  
  Print verbose output.
  
* _PATH_  
  Path of the file to use as input.
