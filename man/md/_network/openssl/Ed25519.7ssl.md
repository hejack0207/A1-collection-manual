# Name

Ed25519, Ed448 - EVP_PKEY Ed25519 and Ed448 support

<a name="description"></a>

# Description

.IX Header "DESCRIPTION"
The **Ed25519** and **Ed448** \s-1EVP_PKEY\s0 implementation supports key generation,
one-shot digest sign and digest verify using PureEdDSA and **Ed25519** or **Ed448**
(see \s-1RFC8032\s0). It has associated private and public key formats compatible with
\s-1RFC 8410.\s0

No additional parameters can be set during key generation, one-shot signing or
verification. In particular, because PureEdDSA is used, a digest must **\s-1NOT\s0** be
specified when signing or verifying.

<a name="notes"></a>

# Notes

.IX Header "NOTES"
The PureEdDSA algorithm does not support the streaming mechanism
of other signature algorithms using, for example, **EVP\_DigestUpdate()**.
The message to sign or verify must be passed using the one-shot
**EVP\_DigestSign()** and **EVP\_DigestVerify()** functions.

When calling **EVP\_DigestSignInit()** or **EVP\_DigestVerifyInit()**, the
digest **type** parameter **\s-1MUST\s0** be set to **\s-1NULL\s0**.

Applications wishing to sign certificates (or other structures such as
CRLs or certificate requests) using Ed25519 or Ed448 can either use **X509\_sign()**
or **X509\_sign\_ctx()** in the usual way.

A context for the **Ed25519** algorithm can be obtained by calling:

.Vb 1
 EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_ED25519, NULL);
.Ve

For the **Ed448** algorithm a context can be obtained by calling:

.Vb 1
 EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_ED448, NULL);
.Ve

Ed25519 or Ed448 private keys can be set directly using
**EVP\_PKEY\_new\_raw\_private\_key**\|(3) or loaded from a PKCS#8 private key file
using **PEM\_read\_bio\_PrivateKey**\|(3) (or similar function). Completely new keys
can also be generated (see the example below). Setting a private key also sets
the associated public key.

Ed25519 or Ed448 public keys can be set directly using
**EVP\_PKEY\_new\_raw\_public\_key**\|(3) or loaded from a SubjectPublicKeyInfo
structure in a \s-1PEM\s0 file using **PEM\_read\_bio\_PUBKEY**\|(3) (or similar function).

Ed25519 and Ed448 can be tested within **speed**\|(1) application since version 1.1.1.
Valid algorithm names are **ed25519**, **ed448** and **eddsa**. If **eddsa** is
specified, then both Ed25519 and Ed448 are benchmarked.

<a name="examples"></a>

# Examples

.IX Header "EXAMPLES"
This example generates an **\s-1ED25519\s0** private key and writes it to standard
output in \s-1PEM\s0 format:

.Vb 9
 #include &lt;openssl/evp.h&gt;
 #include &lt;openssl/pem.h&gt;
 ...
 EVP_PKEY *pkey = NULL;
 EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_ED25519, NULL);
 EVP_PKEY_keygen_init(pctx);
 EVP_PKEY_keygen(pctx, &pkey);
 EVP_PKEY_CTX_free(pctx);
 PEM_write_PrivateKey(stdout, pkey, NULL, NULL, 0, NULL, NULL);
.Ve
