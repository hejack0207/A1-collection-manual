# Name

X25519, X448 - EVP_PKEY X25519 and X448 support

<a name="description"></a>

# Description

.IX Header "DESCRIPTION"
The **X25519** and **X448** \s-1EVP_PKEY\s0 implementation supports key generation and
key derivation using **X25519** and **X448**. It has associated private and public
key formats compatible with \s-1RFC 8410.\s0

No additional parameters can be set during key generation.

The peer public key must be set using **EVP\_PKEY\_derive\_set\_peer()** when
performing key derivation.

<a name="notes"></a>

# Notes

.IX Header "NOTES"
A context for the **X25519** algorithm can be obtained by calling:

.Vb 1
 EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_X25519, NULL);
.Ve

For the **X448** algorithm a context can be obtained by calling:

.Vb 1
 EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_X448, NULL);
.Ve

X25519 or X448 private keys can be set directly using
**EVP\_PKEY\_new\_raw\_private\_key**\|(3) or loaded from a PKCS#8 private key file
using **PEM\_read\_bio\_PrivateKey**\|(3) (or similar function). Completely new keys
can also be generated (see the example below). Setting a private key also sets
the associated public key.

X25519 or X448 public keys can be set directly using
**EVP\_PKEY\_new\_raw\_public\_key**\|(3) or loaded from a SubjectPublicKeyInfo
structure in a \s-1PEM\s0 file using **PEM\_read\_bio\_PUBKEY**\|(3) (or similar function).

<a name="examples"></a>

# Examples

.IX Header "EXAMPLES"
This example generates an **X25519** private key and writes it to standard
output in \s-1PEM\s0 format:

.Vb 9
 #include &lt;openssl/evp.h&gt;
 #include &lt;openssl/pem.h&gt;
 ...
 EVP_PKEY *pkey = NULL;
 EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_X25519, NULL);
 EVP_PKEY_keygen_init(pctx);
 EVP_PKEY_keygen(pctx, &pkey);
 EVP_PKEY_CTX_free(pctx);
 PEM_write_PrivateKey(stdout, pkey, NULL, NULL, 0, NULL, NULL);
.Ve

The key derivation example in **EVP\_PKEY\_derive**\|(3) can be used with
**X25519** and **X448**.
