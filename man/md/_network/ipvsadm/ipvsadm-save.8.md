# ipvsadm-save(8) - save the IPVS table to stdout

LVS Administration, 22nd March 2001

```
ipvsadm-save [-n]
```

<a name="description"></a>

# Description

ipvsadm-save prints the IPVS table to stdout.

<a name="options"></a>

# Options

The option that is recognized by
**ipvsadm-save**
is:

* **-n**  
  print out the table in numeric format.
