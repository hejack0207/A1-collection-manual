Jan Chaloupka,  etcd User Manuals


etcdctl - A simple command line client for etcd



<a name="synopsis"></a>

# Synopsis

```

 [ETCDCTL_API=3] etctctl [OPTIONS]
```



<a name="description"></a>

# Description


Command line client for etcd.
Queries to v2 data model are available through **etcdtl** command (see **etcdctl2(1)**).
Queries to v3 data model are available through **ETCDCTL=3 etcdtl** command (see **etcdctl3(1)**).


Find more information at 
\[la]https://github.com/coreos/etcd\[ra].
