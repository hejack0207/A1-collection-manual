# Name


etcdctl-endpoint-status - Prints out the status of endpoints specified in **\fC--endpoints** flag



<a name="synopsis"></a>

# Synopsis

```

 ETCDCTL=3 etcdctl endpoint status [flags]
```



<a name="description"></a>

# Description


When --write-out is set to simple, this command prints out comma-separated status lists for each endpoint.
The items in the lists are endpoint, ID, version, db size, is leader, raft term, raft index.
