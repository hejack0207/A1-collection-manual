# pwdx(1) - report current working directory of a process

procps-ng, June 2011

```
pwdx [options] pid [...]
```

<a name="options"></a>

# Options


* **-V**, **--version**  
  Output version information and exit.
* **-h**, **--help**  
  Output help screen and exit.
