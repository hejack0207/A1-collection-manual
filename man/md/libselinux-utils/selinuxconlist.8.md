# selinuxconlist(1) - list all SELinux context reachable for user

dwalsh@redhat.com, 7 May 2008

```
selinuxconlist [-l level] user [context]
```


<a name="description"></a>

# Description

**selinuxconlist**
reports the list of context reachable for user from the current context or specified context

**-l level**
mcs/mls level
