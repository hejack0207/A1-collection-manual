# pslog(1)

September 12, 2015” 

pslog- report current logs path of a process


<a name="synopsis"></a>

# Synopsis

    pslog pid...
    pslog -V


<a name="description"></a>

# Description

The pslog command reports the current working logs of a process.


<a name="general-options"></a>

# General Options

l l l.
-V  show version  Displays version of program.
