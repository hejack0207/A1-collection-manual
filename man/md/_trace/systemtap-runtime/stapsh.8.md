# stapsh(8)

stapsh


<a name="synopsis"></a>

# Synopsis


```

stapsh
```


<a name="description"></a>

# Description


The stapsh executable is used by the stap
_--remote_
functionality, as a wrapper shell on the remote machines. 
It is not intended to be run directly by users.
