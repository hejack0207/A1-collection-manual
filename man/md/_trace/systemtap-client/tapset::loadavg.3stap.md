# tapset::loadavg(3stap) - systemtap loadavg tapset

SystemTap Tapset Reference, May 2021


<a name="description"></a>

# Description


 Functions in the loadavg tapset allow a probe handler to capture
 the load average.


* 

* **get_loadavg_index**  
  Get the load average for a specified interval
* See 
  _function::get_loadavg_index_(3stap)
   for details.


* **sprint_loadavg**  
  Report a pretty-printed load average
* See 
  _function::sprint_loadavg_(3stap)
   for details.
