# tapset::inet(3stap) - systemtap inet tapset

SystemTap Tapset Reference, May 2021


<a name="description"></a>

# Description


* 

* **htonll**  
  Convert 64-bit long long from host to network order
* See 
  _function::htonll_(3stap)
   for details.


* **htonl**  
  Convert 32-bit long from host to network order
* See 
  _function::htonl_(3stap)
   for details.


* **htons**  
  Convert 16-bit short from host to network order
* See 
  _function::htons_(3stap)
   for details.


* **ntohll**  
  Convert 64-bit long long from network to host order
* See 
  _function::ntohll_(3stap)
   for details.


* **ntohl**  
  Convert 32-bit long from network to host order
* See 
  _function::ntohl_(3stap)
   for details.


* **ntohs**  
  Convert 16-bit short from network to host order
* See 
  _function::ntohs_(3stap)
   for details.
