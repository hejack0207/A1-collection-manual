# Description


* 

* **matched_str**  
  Return the last matched string.
* See 
  _function::matched_str_(3stap)

* **matched**  
  Return a given matched subexpression.
* See 
  _function::matched_(3stap)
   for details.


* **ngroups**  
  Number of subexpressions in the last match.
* See 
  _function::ngroups_(3stap)
   for details.
