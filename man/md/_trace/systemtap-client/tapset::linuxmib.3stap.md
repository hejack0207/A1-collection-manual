# tapset::linuxmib(3stap) - systemtap linuxmib tapset

SystemTap Tapset Reference, May 2021

# Description


* 

* **linuxmib.DelayedACKs**  
  Count of delayed acks
*  See 
  _probe::linuxmib.DelayedACKs_(3stap)
   for details.


* **linuxmib.ListenOverflows**  
  Count of times a listen queue overflowed
*  See 
  _probe::linuxmib.ListenOverflows_(3stap)
   for details.


* **linuxmib.ListenDrops**  
  Count of times conn request that were dropped
*  See 
  _probe::linuxmib.ListenDrops_(3stap)
   for details.


* **linuxmib.TCPMemoryPressures**  
  Count of times memory pressure was used
*  See 
  _probe::linuxmib.TCPMemoryPressures_(3stap)
   for details.
