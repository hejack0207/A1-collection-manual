# tapset::speculative(3stap) - systemtap speculative tapset

SystemTap Tapset Reference, May 2021


<a name="description"></a>

# Description


* 

* **speculation**  
  Allocate a new id for speculative output
* See 
  _function::speculation_(3stap)
   for details.


* **speculate**  
  Store a string for possible output later
* See 
  _function::speculate_(3stap)
   for details.


* **discard**  
  Discard all output related to a speculation buffer
* See 
  _function::discard_(3stap)
   for details.


* **commit**  
  Write out all output related to a speculation buffer
* See 
  _function::commit_(3stap)
   for details.
