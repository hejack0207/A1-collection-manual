# tapset::tzinfo(3stap) - systemtap tzinfo tapset

SystemTap Tapset Reference, May 2021


<a name="description"></a>

# Description


* 

* **tz_gmtoff**  
  Return local time zone offset
* See 
  _function::tz_gmtoff_(3stap)
   for details.


* **tz_name**  
  Return local time zone name
* See 
  _function::tz_name_(3stap)
   for details.


* **tz_ctime**  
  Convert seconds since epoch into human readable date/time string, with local time zone
* See 
  _function::tz_ctime_(3stap)
   for details.
