# tapset::stopwatch(3stap) - systemtap stopwatch tapset

SystemTap Tapset Reference, May 2021


<a name="description"></a>

# Description


* 

* **delete_stopwatch**  
  Remove an existing stopwatch
* See 
  _function::delete_stopwatch_(3stap)
   for details.


* **start_stopwatch**  
  Start a stopwatch 
* See 
  _function::start_stopwatch_(3stap)
   for details.


* **stop_stopwatch**  
  Stop a stopwatch 
* See 
  _function::stop_stopwatch_(3stap)
   for details.


* **read_stopwatch_ns**  
  Reads the time in nanoseconds for a stopwatch
* See 
  _function::read_stopwatch_ns_(3stap)
   for details.


* **read_stopwatch_us**  
  Reads the time in microseconds for a stopwatch
* See 
  _function::read_stopwatch_us_(3stap)
   for details.


* **read_stopwatch_ms**  
  Reads the time in milliseconds for a stopwatch
* See 
  _function::read_stopwatch_ms_(3stap)
   for details.


* **read_stopwatch_s**  
  Reads the time in seconds for a stopwatch
* See 
  _function::read_stopwatch_s_(3stap)
   for details.
