# grub-mkrelpath(3) - Generate a relative GRUB path given an OS path.

Wed Feb 26 2014

```
grub-mkrelpath FILE
```


<a name="description"></a>

# Description

**grub-mkrelpath** takes an OS filesystem path for _FILE_ and returns a relative path suitable for use in a GRUB configuration file.
