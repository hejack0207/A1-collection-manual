# grub-mkconfig(1) - Generate a GRUB configuration file.

Wed Feb 26 2014

```
grub-mkconfig [-o | --output=FILE]
```


<a name="description"></a>

# Description

**grub-mkconfig** generates a configuration file for GRUB.


<a name="options"></a>

# Options


* **--output**=_FILE_  
  Write generated output to _FILE_.
  
* **--no-grubenv-update**  
  Do not update variables in the grubenv file.
