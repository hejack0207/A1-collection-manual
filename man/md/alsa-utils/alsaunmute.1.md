# alsaunmute(1) - a simple script to initialize ALSA sound devices

21 April 2010


<a name="description"></a>

# Description

**alsaunmute** is a shell script which runs the **alsactl(1)**
utility with _init_ argument (see the script for details).


<a name="options"></a>

# Options

None

.SS
Example:
**alsaunmute**
