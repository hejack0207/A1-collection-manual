<a name="name"></a>

# Name

perf-version - display the version of perf binary

<a name="synopsis"></a>

# Synopsis

```

 perf version [--build-options]
```

<a name="description"></a>

# Description


With no options given, the _perf version_ prints the perf version on the standard output.

If the option _--build-options_ is given, then the status of compiled-in libraries are printed on the standard output.

<a name="options"></a>

# Options


--build-options
Prints the status of compiled-in libraries on the standard output.
