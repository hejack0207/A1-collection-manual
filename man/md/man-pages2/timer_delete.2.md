# timer_delete(2) - delete a POSIX per-process timer

Linux, 2015-08-08

     #include <time.h>
    
    int timer_delete(timer_t timerid);

<a name="description"></a>

# Description

**timer_delete**()
deletes the timer whose ID is given in
_timerid_.
If the timer was armed at the time of this call,
it is disarmed before being deleted.
The treatment of any pending signal generated by the deleted timer
is unspecified.

<a name="return-value"></a>

# Return Value

On success,
**timer_delete**()
returns 0.
On failure, -1 is returned, and
_errno_
is set to indicate the error.

<a name="errors"></a>

# Errors


* **EINVAL**  
  _timerid_
  is not a valid timer ID.

<a name="versions"></a>

# Versions

This system call is available since Linux 2.6.
