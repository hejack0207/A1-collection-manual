# lvmsadc(8) - LVM system activity data collector

Red Hat, Inc, LVM TOOLS 2.02.183(2) (2018-12-07)

```
lvmsadc
```

<a name="description"></a>

# Description

lvmsadc is not supported under LVM2. The device-mapper statistics
facility provides similar performance metrics using the **dmstats(8)**
command.
