ERROR REPORTING
       When an error is detected, nft shows the line(s) containing the error, the position of the erroneous parts in the input stream and marks up the erroneous parts using carets  (^).
       If the error results from the combination of two expressions or statements, the part imposing the constraints which are violated is marked using tildes (~).

       For errors returned by the kernel, nft can't detect which parts of the input caused the error and the entire command is marked.

       Error caused by single incorrect expression

       <cmdline>:1:19-22: Error: Interface does not exist
       filter output oif eth0
                         ^^^^

       Error caused by invalid combination of two expressions

       <cmdline>:1:28-36: Error: Right hand side of relational expression (==) must be constant
       filter output tcp dport == tcp dport
                               ~~ ^^^^^^^^^

       Error returned by the kernel

       <cmdline>:0:0-23: Error: Could not process rule: Operation not permitted
       filter output oif wlan0
       ^^^^^^^^^^^^^^^^^^^^^^^
