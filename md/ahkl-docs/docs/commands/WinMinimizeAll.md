# WinMinimizeAll / WinMinimizeAllUndo

Minimizes or unminimizes all windows.

```
<span class="func">WinMinimizeAll</span>
<span class="func">WinMinimizeAllUndo</span>

```

On most systems, this is equivalent to Explorer's Win+M and Win+D hotkeys.

## Related

[WinMinimize](WinMinimize.htm), [GroupAdd](GroupAdd.htm)

## Examples

Minimizes all windows for 1 second and unminimizes them.

```
WinMinimizeAll
Sleep, 1000
WinMinimizeAllUndo
```
