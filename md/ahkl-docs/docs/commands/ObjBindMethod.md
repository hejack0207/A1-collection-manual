# ObjBindMethod() [v1.1.20+]

Creates a [BoundFunc object](../objects/Functor.htm#BoundFunc) which calls a method of a given object.

```
BoundFunc := <span class="func">ObjBindMethod</span>(Obj, Method, <i>Params</i>)
```

## Parameters

Obj

Any object.

Method

A method name.

_Params_

Any number of parameters.

## Remarks

For details and examples, see [BoundFunc object](../objects/Functor.htm#BoundFunc).
