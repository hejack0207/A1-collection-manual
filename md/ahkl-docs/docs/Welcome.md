# Welcome...

## Getting Started

Before AutoHotkey can do anything, you need to write a script telling it what to do.

To learn how, read [the tutorial](Tutorial.htm) or [dive straight in](Scripts.htm).

Basically: [create a script file](Tutorial.htm#s12) → [add some hotkeys](Tutorial.htm#s2) → run the script file.

You can also get help or find many useful scripts on [our friendly discussion forum](https://www.autohotkey.com/boards/).

## Why am I seeing this?

You ran AutoHotkey without [telling it](Scripts.htm#cmd) which script file to run, and it couldn't find a script in either of [the usual places](Scripts.htm#defaultfile).
